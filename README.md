# Website Resmi Madrasah Khairul Falah

> Redesign identitas 2027/2028: lihat [audit, sumber konten, aset, pengujian, dan keputusan publikasi](docs/REDESIGN_2027_2028.md). MI: Madrasah Adab & Life Skills. MTs: Madrasah Digital Creator. Filosofi Yayasan: **DIBENTUK, bukan hanya diajar.**

> Website resmi Madrasah Khairul Falah yang dibangun menggunakan **Astro**, **TypeScript**, dan **Tailwind CSS** dengan fokus pada performa, aksesibilitas, SEO, dan pengalaman pengguna yang modern.

---

## 🎯 Project Vision

Membangun website madrasah yang tidak hanya menjadi media informasi, tetapi juga menjadi wajah transformasi pendidikan Madrasah Khairul Falah.

Website ini dirancang untuk:

* Meningkatkan citra dan branding madrasah.
* Mendukung PPDB melalui pengalaman pengguna yang baik.
* Menampilkan Kurikulum Khairul Falah Learning Framework (KFLF).
* Menjadi pusat informasi bagi calon orang tua, siswa, guru, alumni, dan masyarakat.
* Menjadi fondasi ekosistem digital Madrasah Khairul Falah.
